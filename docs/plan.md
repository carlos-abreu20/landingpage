#Projeto de Landing Page para App Fitness

Página com fundo branco e fonte Roboto como principal.

## Seção HEADER:

Logo no canto esquerdo:
- A logo é um F em círculo (feito com CSS)
- O fundo do círculo é VERDE ESCURO

Botão de download no canto direito:
- fundo verde, cor branca
- borda arredondada

## Seção HERO:
A hero deve ter altura 90vh, dividido em 3 áreas horizontas

Esquerda:
- Apenas a headline, sem ser grande demais, sem destaque (o destaque é o print do app no meio).
"O app perfeito para compartilhar sua vida fitness."

CENTRO:
- E destaque a imagem imagens/print_1.png que é um print do app.

DIREITA:
Uma lista de pontos-chave sobre o app:
-❤️ Saúde
-🏃‍♂️ Exexcício
-🧑‍🤝‍🧑 Amigos

## SEÇÃO de FUNCIONALIDADES:
Vão ser usadas as imagens imagens/print_2.png, imagens/print_3.png e imagens/print_4.png que serão exibidas da seguinte forma:
- print / texto
- texto / print
- print / texto
ou seja, irá alternar entre o print na esquerda e um texto explicativo na direita, vice-versa.

Descrição breve de cada print para você gerar um texto adequado:
- print_2.png = Contagem de calorias
- print_3.png = Exercícios específicos (corrida, musculação, etc)
- print_4.png = Compartilhamento com amigos

## SEÇÃO DE CTA (Call-to-action):
Botão grande de download com um texto abaixo dele destacando: "Totalmente gratuito"

## Seção de RODAPÉ:
Apenas com o texto : "todos os direitos reservados"
